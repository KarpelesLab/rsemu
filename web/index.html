Controller 1: Z A, X B, Enter Start, Shift Select, arrows for the d-pad. They reach the console's controller port at $4016, which samples them whenever the game strobes it — a level, not an event, which is what makes a recorded session replayable.

What this is



  The same emulator that runs natively, built for
  wasm32-unknown-unknown and driven from
  requestAnimationFrame. No wasm-bindgen: the module
  exports plain C functions and rsemu.js is the entire glue.




  This page deliberately does not need cross-origin isolation. The
  threaded configuration needs SharedArrayBuffer and therefore
  COOP/COEP, which is often unavailable — so the non-threaded path is a
  supported target rather than a fallback, and it is the one shipped here
  (ROADMAP.md §11.3).




  Virtual time is computed inside the emulator, never read from the host clock,
  so a run here produces the same state hash as the same run under a native
  debugger (ROADMAP.md §11.6). The hash is on screen; compare it
  with what rsemu run prints.
