# Read this before adding a line. Conformance here is defined as *our
# signature equals the reference model's signature, byte for byte* — so a
# difference is one of exactly three things, and they are not interchangeable:
#
#   * a defect in this core. Fix it; do not write it down.
#   * a place where the ISA genuinely leaves the choice to the implementation
#     and the reference model was configured to make the other one. Say which
#     specification paragraph grants the choice, and which way each side went.
#     Better still, configure the reference model to agree — that is what
#     scripts/fetch-testdata.sh's config override is for, and an entry here is
#     an admission that it could not be done.
#   * a defect in the test. Rare, and it needs the specification quoted before
#     it is claimed (`CLAUDE.md`: a corpus is evidence, not authority).
